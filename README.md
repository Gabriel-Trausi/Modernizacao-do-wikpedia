# Modernização da Wikipédia: Rockstar Games

Projeto desenvolvido para fins de estudo com a proposta de modernizar a apresentação de artigos no estilo da Wikipédia. O tema escolhido foi a Rockstar Games e algumas de suas principais franquias.

O site reúne informações sobre a empresa e páginas dedicadas a **Bully**, **Grand Theft Auto**, **Manhunt**, **Max Payne** e **Red Dead Redemption**. A interface foi construída como um exercício de prática de HTML, CSS e JavaScript.

## Objetivos

- Praticar a criação e a organização de páginas com HTML.
- Aplicar estilos compartilhados e adaptar a apresentação do conteúdo com CSS.
- Implementar interações simples com JavaScript.
- Reimaginar visualmente a navegação e a leitura de artigos enciclopédicos.

## Funcionalidades

- Navegação entre a página principal e os artigos das franquias.
- Índice de seções para facilitar a navegação pelos artigos.
- Alternância entre tema claro e escuro, com preferência salva no navegador.
- Layout com navegação lateral, área principal de leitura e índice de seções.
- Links e referências para consulta das fontes utilizadas.

## Tecnologias

- HTML5
- CSS3
- JavaScript

O projeto não utiliza frameworks nem exige instalação de dependências.

## Como visualizar

1. Baixe ou clone este repositório.
2. Abra o arquivo `Index.html` em um navegador.
3. Use o menu lateral para acessar os demais artigos.

Também é possível abrir a pasta no Visual Studio Code e executar o arquivo com uma extensão de servidor local, como o Live Server.

## Uso de inteligência artificial

Ferramentas de inteligência artificial foram utilizadas como apoio durante a produção e a modernização dos códigos, incluindo sugestões e assistência na implementação de HTML, CSS e JavaScript. O uso da IA fez parte do processo de estudo; o projeto não representa um produto oficial da Wikipédia nem da Rockstar Games.
